Dynamic Documentary Engine

Clip library

Label each clip so the engine can contrast it and bring it up as a memory. Changes save as you type.

A cue typed in the console's Memory triggers brings up clips whose title, tag, theme, person, place, mood or weather is exactly that word or phrase (capitals don't matter). Dates can be typed as 18 December 1944, December 1944 or 1944.

View only. Labels can be changed on the computer running the engine, so a shared link can never alter the tagging.

Labels are saved to this topic's clip list and used by the very next film. Earlier versions are kept as backups.
